# GAUTAMORA PRIVATE LIMITED — Website Starter

Premium corporate website starter (Hindi + English) for a garments manufacturing company.

## Included
- Responsive corporate homepage
- Product category section
- Manufacturing, quality and distribution sections
- Business enquiry form UI (demo only; no backend submission yet)
- Login entry point and ERP dashboard preview (demo UI only)
- Navy/white design system

## Run locally
1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Important
This is the first frontend starter, not a production ERP. Authentication, database, customer records,
approvals, inventory transactions, payments, notifications and deployment must be connected to a
secure backend before real business use. Replace placeholder contact details and verify legal company
name/brand details before publishing.
